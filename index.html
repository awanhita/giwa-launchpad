Create a launch

Issues a new token + bonding curve (ALC) on an existing Config. The Config decides the curve, fees and graduation. You pay only gas — the pool creation fee on template Configs is 0. You are the token Creator.

Decimals are fixed by the Config (template #6 uses 9). The launch is immutable once created.

My Configs

A Config is a reusable, immutable policy (supply, curve, fees, graduation, recipients) derived from reviewed template #6. One Config can launch many tokens. Creating a Config costs only gas.
